# PRODUCT.md — Flux Platform Vision & Feature Matrix

> **Source**: Extracted from `prompt/1/01.md` and `prompt/1/02.md`.

## 1. Product Vision & Goals
Flux is a production-grade, multi-tier URL shortening, link management, dynamic routing, analytics, SaaS monetization, and enterprise attribution platform.

## 2. Platform Tier Matrix
- **Tier 1: Core Platform**: Base62 shortening, high-performance redirects, basic analytics ingestion, rate limiting.
- **Tier 2: Flux Growth**: Campaign management, UTM builder, custom domains, smart geo/device routing, deep linking, dynamic OG metadata, A/B testing.
- **Tier 3: Flux SaaS**: Organizations, multi-tenancy, RBAC, Stripe billing, public REST API, OAuth 2.0, Webhooks, notifications.
- **Tier 4: Flux Enterprise**: Multi-touch attribution (First, Last, Linear, Decay, U-Shaped), conversion funnels, revenue metrics, predictive AI engine, SAML/SCIM SSO.
- **Tier 5: Global Scale**: Multi-region edge redirect engine (Cloudflare Workers / Fly.io), geo-replicated DBs, Anycast DNS, global HA.

## 3. Explicit Non-Goals
- Flux is NOT a general-purpose CMS or website builder.
- Flux does NOT store raw un-aggregated analytics logs in primary OLTP database.
