# ROADMAP.md — Flux Tiered Architecture Roadmap

> **Source**: Extracted from `prompt/1/01.md` through `prompt/5/05.md`.

## 1. Evolution Phases
1. **Phase 1 (Core Platform)**: Build Modular Monolith in Go, PostgreSQL storage, Redis caching, Kafka click event stream.
2. **Phase 2 (Growth Tier)**: Integrate ClickHouse time-series DB, custom domain DNS automation, smart routing engine, async worker queues.
3. **Phase 3 (SaaS Tier)**: Implement organization multi-tenancy, Stripe billing integration, public REST API, Webhook engine.
4. **Phase 4 (Enterprise Tier)**: Implement attribution engine models, SAML 2.0 / SCIM 2.0, automated malware scanning.
5. **Phase 5 (Global Scale)**: Deploy Cloudflare Workers edge redirect engine, geo-distributed database replication, Anycast DNS.
