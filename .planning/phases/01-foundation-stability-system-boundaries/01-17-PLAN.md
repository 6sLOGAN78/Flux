| Job payload/driver errors to telemetry | Private mail data, credentials and opaque provider messages |
| Process telemetry to collector/exporter | Remote service and monitoring-vendor transport |

| T-05-02 | Spoofing | Request/job correlation | mitigate | Validate UUID/W3C metadata, replace invalid input, ignore baggage |
| T-05-03 | Denial of service | Metrics/export queues | mitigate | Fixed labels, bounded SDK queues/attributes, batching and export deadlines |

| T-05-SC | Tampering | Go telemetry modules/collector image | mitigate | Official exact release resolution, module checksums and image digest; no npm/pip/cargo installs |
