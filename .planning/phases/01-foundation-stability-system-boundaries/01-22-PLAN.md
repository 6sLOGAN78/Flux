<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Contributor branch to CI runner/token | Untrusted repository code |
| Official release/package metadata to developer/CI tools | Binary and dependency supply chain |
| Scanner findings to CI logs/artifacts | Discovered secrets and sensitive diagnostics |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Elevation of privilege | CI workflow | mitigate | Read-only token, no privileged pull_request_target execution or production secrets |
| T-06-02 | Tampering | Tool/action downloads | mitigate | Official URLs, action commit SHAs, exact tool versions and checksum verification |
| T-06-03 | Information disclosure | Secret/dependency scanning | mitigate | Capture privately, sanitized finding output, redact flags, no raw report uploads |
| T-06-04 | Denial of service | CI subprocesses | mitigate | Explicit timeouts, bounded diagnostic outputs, cancellation of obsolete runs |
| T-06-05 | Repudiation | Green but incomplete checks | mitigate | Complete stage/package manifest and deliberate failure fixture tests |
| T-06-SC | Tampering | Dependency graph | mitigate | Frozen root Bun lock, go.sum verification, pinned standalone scanners; no new npm/pip/cargo installs |

Scope this register to the owned files in this plan; the remaining original boundary mitigations belong to the adjacent source-task fragments.
