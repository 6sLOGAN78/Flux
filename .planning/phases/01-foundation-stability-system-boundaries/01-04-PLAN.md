## Assets
- Database credentials, migration integrity, resource availability, and shutdown diagnostics.

## Trust Boundaries
| Boundary | Risk |
|---|---|
| Environment variables to typed configuration | Secret disclosure or incompatible key changes |
| Migrator binary to PostgreSQL | Unauthorized/destructive schema execution or DSN leakage |
| Cleanup callbacks to logs | Raw provider errors disclose hostnames or credentials |

## Threats and Mitigations
| Threat ID | Category | Component | Disposition | Mitigation and verification |
|---|---|---|---|---|
| T-02-01 | Information Disclosure | Config/migration errors | mitigate | Typed wrapped internal errors; logs exclude DSNs/passwords and tests use marker secrets |
| T-02-02 | Tampering | Migration execution | mitigate | Embedded numbered migrations, explicit one-shot role, exact version assertions |
| T-02-03 | Denial of Service | Partial startup/cleanup | mitigate | Register immediately, reverse close, attempt all, join errors, idempotency tests |
| T-02-04 | Repudiation | Migration result | mitigate | Structured start/end version and process outcome without sensitive diagnostics |
| T-02-SC | Tampering | PostgreSQL test image | mitigate | Exact verified image pin inherited from Plan 01 and frozen Go module checksums |

## Verification
