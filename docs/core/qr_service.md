1. Product Requirement & Goal

Build an enterprise QR code generation engine supporting branding customization, error correction, high resolution vector exports, and high-throughput batch generation.

Key Features:
- Embedded logo overlays (center branding).
- Custom HSL colors (foreground, background, eye frame, eye ball).
- Custom frame shapes (Square, Rounded, Circle, Dots).
- Error Correction Levels: L (7%), M (15%), Q (25%), H (30%).
- Vector (SVG) & High-Res Raster (PNG, WEBP) exports.
- Asynchronous batch ZIP generator for bulk QR creation.

2. Architecture & API Contract

```sql
CREATE TABLE IF NOT EXISTS qr_customizations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    link_id UUID NOT NULL REFERENCES links(id) ON DELETE CASCADE,
    logo_url TEXT,
    fg_color VARCHAR(10) DEFAULT '#000000',
    bg_color VARCHAR(10) DEFAULT '#FFFFFF',
    eye_color VARCHAR(10) DEFAULT '#000000',
    error_correction VARCHAR(2) DEFAULT 'H', -- 'L', 'M', 'Q', 'H'
    dot_style VARCHAR(20) DEFAULT 'square', -- 'dots', 'rounded', 'square'
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

- `GET /api/v1/qr/:link_id?format=png&size=1024&download=true` -> Returns binary image buffer.
- `POST /api/v1/qr/batch`
  Request: `{ "link_ids": ["id1", "id2", "id3"], "format": "zip" }`
  Response: `{ "job_id": "qr_batch_789", "download_url": "/api/v1/qr/jobs/qr_batch_789.zip" }`

3. Implementation Step-by-Step

Step 1: Integrate high-speed QR engine library (`qrcode` / Go `skip2/go-qrcode`) with SVG/Canvas overlay engine.
Step 2: Implement Redis L2 binary caching for generated QR images (`qr:link_id:format:hash`).
Step 3: Build background worker queue for zip bundle generation of up to 10,000 QR codes per job.
